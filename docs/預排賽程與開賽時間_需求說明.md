# 預排賽程與開賽時間：公開 feed 的兩項增補需求

**提出者**：中華職業圍棋協會秘書處
**對象**：賽程操作台維護者
**日期**：2026-10-16
**現況**：官網已串接 `public_pairings/current`，運作正常，本文只提兩項增補。

---

## 一句話總結

請在公開 feed 裡**多放「已排定但還沒抽籤」的場次**，並**把開賽時間填上**。
這兩項我們自己都推算不出正確答案，只有操作台知道。

---

## 需求一：預排賽程

### 現在的問題

棋士登入官網看「我的賽程」，目前只看得到已經抽好籤的對局。
以 2026-10-16 為例，全站只有 8 筆對局（中環碁聖 16 強那一輪），**今天之後一筆都沒有**。

但棋士實際上同時還在好幾個棋戰裡。以賴均輔為例：

| 棋戰 | 最近一戰 | 接下來 |
|---|---|---|
| 棋王賽 | 10/13 循環圈 勝 | 10/20 循環圈第 7 輪 |
| 中環碁聖賽 | 10/16 16 強（今天） | 10/23 8 強 |
| 中環國手賽 | 10/05 本賽 16 強 勝 | 11/02 8 強 |
| 玄樂盃 | 10/15 本賽 4 強 勝 | 日曆上查不到 |

他畫面上只會看到今天那一場，會以為系統壞了。

### 為什麼我們不自己算

我們手上有海峰的公開日曆（知道 10/20 有棋王循環圈）和成績系統（知道誰打到哪一輪），
理論上可以推算。但推算會出錯，而且錯的代價是讓棋士白跑一趟：

> 同樣是「棋王賽」，賴均輔在**循環圈**，牛詩特在**初賽敗部**。
> 只比對賽事名稱的話，10/20 的循環圈第 7 輪會被算到牛詩特頭上，
> 通知他去一個他不用去的場次。

階段名稱兩邊也對不上（成績系統寫「本賽 16 強」，日曆寫「16強」），
而玄樂盃的日程日曆上根本沒有。這些在操作台那邊都是確定的資料。

### 希望的格式

**不需要新的資料結構**，沿用現有 `public_pairings/current` 的那一份就好，
把預排的場次一起放進 `pairings` 陣列，差別只在 `players` 可以留空或只填已知的一方：

```json
{
  "date": "2026-10-20",
  "event": "第19屆棋王賽",
  "round": "循環圈 第7輪",
  "time": "10:00",
  "players": [],
  "status": "scheduled",
  "id": "qiwang__19:r7"
}
```

| 欄位 | 說明 |
|---|---|
| `date` | 必要。已排定的日期 |
| `event` / `round` | 必要。同現有格式 |
| `time` | 有就填，見需求二 |
| `players` | **可以是空陣列**。已知其中一方就填一個也可以 |
| `status` | 新增，用來區分：`scheduled` = 已排定未抽籤，`drawn` = 已抽籤（現有資料視同 drawn） |
| `id` | 同現有規則，供改期對應用 |

如果加 `status` 欄位不方便，我們也可以直接用「`players` 是不是空的」來判斷，
不過有 `status` 比較不會誤判，麻煩的話就省略。

### 官網會怎麼顯示

已抽籤的照常顯示對手；預排的顯示成：

```
10/20  第19屆棋王賽・循環圈 第7輪
       對手未定
```

**請不要輸出輪空的場次**——這點沿用先前規格的約定：
「對手未定」代表棋士要到場，「輪空」代表不用到場，兩者不能混在同一個清單裡。

## 需求二：開賽時間

### 現在的問題

海峰的公開日曆上，**19 場賽事全部是「整天」，一個時間都沒有**。
我們現在網站上顯示的時間，是程式自己套上去的慣例值。

而操作台的 feed 裡，129 筆對局中有 68 筆帶了時間，**全部是 10:00 或 14:00**。
換句話說，唯一有真實時間的來源就是操作台。

我們原本套的預設值是 11:00，這個數字在您的資料裡**從來沒有出現過**，
所以我們判斷它是錯的，已經準備拿掉。

### 希望的做法

請盡量把 `time` 欄位填上，包含預排的場次。
以 2026-10-16 中環碁聖 16 強那 8 筆為例，目前 `time` 都是空的。

填了之後官網就直接顯示「10:00 開賽」，不加任何但書。
沒填的我們就只顯示日期、不顯示時間——**我們不會再自己猜時間**。

一天有上下午兩場時，照現有做法分別填 `10:00` 與 `14:00` 即可。
