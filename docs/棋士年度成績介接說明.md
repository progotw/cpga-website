# 棋士「年度成績」自動更新　資料介接說明

**提供者**：中華職業圍棋協會 秘書處
**對象**：海峰棋院網站維護廠商
**日期**：2026-11-03

---

## 一、要解決的事

海峰棋院棋士頁上的「年度成績」區塊目前是人工維護的，頁面上會標示
「(11/1更新)」，實務上一個月更新一次：

```
2026年度成績 (11/1更新)
* 台灣職業賽    4勝3負　勝率57.1%
* 世界賽        0勝0負　勝率0%
* 去年度總成績  1勝5負　勝率16.7%
```

這三行其實可以從海峰成績系統既有的公開對局紀錄算出來。協會已經做好一支
程式每天計算並輸出成一個 JSON 檔，**希望網站端改成讀取這個檔案自動顯示，
不必再人工輸入**。

協會以周俊勛九段核對過，三項數字與貴公司頁面上 11/1 的版本完全相同。

## 二、網址

```
https://cpga.org.tw/assets/data/player-stats.json
```

- 公開唯讀，不需要金鑰，沒有流量限制
- 每天台灣時間 20:30 左右自動更新一次
- UTF-8，約 60 KB
- 跨網域讀取（CORS）開放；用伺服器端抓取亦可

## 三、格式

```json
{
  "schema_version": 1,
  "generated": "2026-11-03T20:30:11+08:00",
  "generated_label": "(11/3更新)",
  "year": 2026,
  "last_year": 2025,
  "count": 139,
  "players": {
    "524D63AB167F4AC82887FD1660977B3E": {
      "name": "周俊勛",
      "domestic":      { "games": 7, "win": 4, "loss": 3, "rate": 57.1, "text": "4勝3負　勝率57.1%" },
      "international": { "games": 0, "win": 0, "loss": 0, "rate": 0,    "text": "0勝0負　勝率0%" },
      "last_year":     { "games": 6, "win": 1, "loss": 5, "rate": 16.7, "text": "1勝5負　勝率16.7%" }
    }
  }
}
```

### 欄位

| 欄位 | 說明 |
|---|---|
| `players` 的鍵 | **棋士編號，與貴公司棋士頁網址上的那一串相同**，例如 `/profession/venue/524D63AB…`。兩邊天生對得起來，不需要另做對照表。 |
| `name` | 棋士姓名，僅供核對用 |
| `domestic` | 台灣職業賽（對局紀錄中分類為「國內」者） |
| `international` | 世界賽（分類為「國際」者） |
| `last_year` | 去年度總成績（前一年全部對局） |
| `games` / `win` / `loss` | 局數、勝、敗 |
| `rate` | 勝率百分比的數值，例如 `57.1` |
| `text` | **已排好的字串**，例如 `4勝3負　勝率57.1%`（中間為全形空格），可直接輸出 |
| `generated_label` | 例如 `(11/3更新)`，對應頁面上原本的「(11/1更新)」 |
| `schema_version` | 格式版本。日後若有不相容的變更會改這個數字，並事先通知 |

### 對應到現有畫面

| 頁面上的項目 | 取值 |
|---|---|
| 2026年度成績 (11/1更新) | `year` ＋ `generated_label` |
| 台灣職業賽 | `players[編號].domestic.text` |
| 世界賽 | `players[編號].international.text` |
| 去年度總成績 | `players[編號].last_year.text` |

直接用 `text` 即可，不需要自行計算或排版。

## 四、實作上的建議

- **不要在每次網頁載入時都去抓**。建議每天排程抓一次存起來，或抓回後快取。
- **抓不到時沿用上次的內容**，不要顯示空白或錯誤訊息。
- 編號若在 `players` 中找不到（例如新進棋士尚未列入），請**維持原本的人工內容**，不要顯示 0 勝 0 負。

## 五、計算方式（供查核）

資料來源是海峰成績系統的公開對局紀錄，每一局都帶有分類欄位：

- 第 2 欄　國內／國際　→ 國內計入台灣職業賽、國際計入世界賽
- 第 3 欄　正式／限制　→ 兩者都計入

勝方欄位等於該棋士本人才算勝，其餘算敗（與成績系統查詢頁一致）。
目前資料中沒有「交流」類的對局；日後若出現，協會會先與海峰確認是否計入，
再調整並通知貴公司。
