# 海峰棋院網站改版　介接需求說明

**提出者**：中華職業圍棋協會（CPGA）秘書處
**對象**：海峰棋院新網站開發廠商
**日期**：2026-11-24（已依樣品站 `haifong.pages.dev` 實測結果修訂）
**協會官網**：<https://cpga.org.tw>

---

## 0. 這份文件要說什麼

中華職業圍棋協會官網目前**每天自動從海峰棋院網站取得資料**，
包括職業棋士名錄、棋士簡介、新聞、比賽訊息、抽籤結果等，並顯示在協會官網上。
協會沒有另外建立一份棋士資料，**院方網站就是唯一的來源**。

協會已針對樣品站（`https://haifong.pages.dev`，暫時網址）實際測試過，
**結論是：新站的做法對協會來說比舊站更好讀**，詳見第 1 節。

這份文件列出測試結果、以及希望貴公司配合的幾件事。
協會這邊的程式都可以自行修改，**只需要事先知道規則**。

---

## 1. 實測結果：很好，請維持現在的做法

| 項目 | 測試結果 |
|---|---|
| 頁面形式 | **純靜態 HTML**，不需要執行 JavaScript 就讀得到內容 ✔ |
| 棋士名錄 `/pros/` | 139 位全部讀得到，與協會名錄**完全一致** ✔ |
| 棋士編號 | 新編號＝**舊編號前 10 碼轉小寫**，139 位**無一重複** ✔ |
| 棋士個人頁 | 段位、歷史成績、年度成績、簡介、棋戰履歷、照片都在 ✔ |
| 新聞列表 `/news/` | 2922 篇的清單直接以 JSON 寫在頁面裡（id／標題／日期／分類／縮圖）✔ |
| 新聞內文 | 完整保留，**抽籤結果公告的對陣表格式與舊站相同** ✔ |

### 特別感謝兩點，請務必保留

**(1) 棋士編號可直接換算**

```
舊：/profession/venue/524D63AB167F4AC82887FD1660977B3E
新：/pros/524d63ab16.html          ← 前 10 碼轉小寫
```

協會原本最擔心的就是編號重新產生（那會導致棋士帳號、對局費、個人 AI 分析
全部對不起來）。現在的做法**完全不必人工對照**，協會可以自動換算。

→ **請在正式上線時維持這個規則。** 若最後決定改用其他編號，
請提供新舊對照表（CSV 即可：`old_id,new_id,name`）。

**(2) 新聞清單的 JSON**

`/news/index.html` 裡的 `const DATA=[…]` 這段，對協會來說比解析畫面穩定太多。
→ **請保留這個做法**；若能再加上「內文」或獨立輸出一份 `news.json`，更好。

## 2. 需要配合的三件事

### 2-1. 舊網址請保留轉址（301）

協會官網與搜尋引擎上有大量舊連結，規則很單純，希望由貴公司在伺服器端處理：

| 舊網址 | 新網址 | 數量 |
|---|---|---|
| `/profession/venue/<32碼大寫>` | `/pros/<前10碼小寫>.html` | 139 |
| `/news/content/<32碼大寫>` | `/news/<前10碼小寫>.html` | 2922 |
| `/profession` | `/pros/` | — |
| `/news` | `/news/` | — |
| `/elite` | `/elite/` | — |

協會官網上 132 篇已轉存新聞的「原文連結」都指向舊網址，
協會這邊會自行改寫，但**外部網站與搜尋引擎上的舊連結只有貴公司能救**。

### 2-2. 圖片：中文檔名的部分目前讀不到

協會官網的新聞是**內文存在協會這邊、圖片仍引用貴院網址**
（當初為了版權與節省貴院儲存空間所做的決定）。目前共引用 **769 張**。

實測樣品站：

| 圖片類型 | 數量 | 樣品站狀態 |
|---|---|---|
| 英數檔名（如 `S__122413098.jpg`） | 256 張 | **讀得到** ✔ |
| **中文檔名**（如 `9吳清源杯臺灣代表選拔-01.jpg`） | **513 張** | **404 讀不到** ✘ |
| 新聞縮圖 `/upload/news/*.jpg` | — | 主站讀得到、圖床讀不到 |

中文檔名那 513 張，舊站目前都正常（HTTP 200）。
若正式上線後仍然讀不到，**協會官網上會有五百多張照片同時變成破圖**。

→ 請確認中文檔名的圖片會一併搬移（可能只是樣品站還沒搬完）。
→ 並請維持 `/upload/...` 的路徑結構，或告知新的對應規則。

### 2-3. 抽籤結果公告的格式請不要改

協會官網的「我的賽程」與棋士個人頁的「今後賽程」，
是解析抽籤結果公告的**正文純文字**取得的：

```
11/11(10:00)：32強對陣
盧奕銓新人王 vs. 黃世元五段
尤浩宇二段 vs. 蘇聖芳四段
```

棋士會依這份資料安排當天行程，顯示錯誤的對手或時間比顯示不出來更嚴重。
樣品站的格式與舊站相同，**請在新站維持這個寫法**；
若日後能改為結構化資料（日期、時間、棋戰、輪次、雙方棋士編號）當然更好。

## 3. 協會的存取方式（供貴公司備查）

- **頻率**：每天台灣時間 **20:17** 一次，單日總請求量約 20～40 次
- **內容**：僅讀取公開頁面，不涉及任何帳號
- **識別**：所有請求都帶有下列 User-Agent，便於貴公司辨識或設定白名單

```
CPGA-site-builder/1.1 (+https://cpga.org.tw; CPGA official site data sync)
```

- 若回應 403 / 429 / 503，協會的程式會自動整批停止、隔天再試
- 協會的程式都設有保護機制：**解析結果異常時會中止並保留原有資料**，
  不會用空資料覆蓋。因此切換當天協會官網不會變空白，但資料會停止更新。

---

## 4. 請在上線前告知

新站的 HTML 結構與舊站不同，協會的五支抓取程式（名錄、棋士頁、新聞、文章、
精銳隊）都需要改寫。改寫本身不難，但**必須等正式網址確定**。

- 需要的時間：**正式網址確定後 1～2 個工作天**
- 希望能在**切換前至少一週**告知預定上線日期與正式網址
- 若能在切換前保留樣品站供測試，最為理想

## 5. 這次改版不會動到的系統（確認用）

院方已表示以下系統**不在改版範圍內**，列出供貴公司確認，避免一併遷移：

| 系統 | 協會官網的用途 |
|---|---|
| 成績系統（對局紀錄資料庫） | 棋士年度成績、近期對局、升段進度 |
| 棋譜系統（HiGO） | 每一局的「看棋譜」連結 |
| 棋士研究室（個人 AI 分析） | 職業棋士專區的個人分析連結 |
| 對局費資料（專用網址） | 棋士對局費與獎金排名 |
| 公開行事曆（Google 日曆） | 全站賽程與賽事月曆 |

**若其中任何一項會跟著調整，請務必事先告知協會**，
否則對應功能會在切換當天停止。
