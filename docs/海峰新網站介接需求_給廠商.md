# 海峰棋院網站改版　介接需求說明

**提出者**：中華職業圍棋協會（CPGA）秘書處
**對象**：海峰棋院新網站開發廠商
**日期**：2026-11-24
**協會官網**：<https://cpga.org.tw>

---

## 0. 這份文件要說什麼

中華職業圍棋協會官網目前**每天自動從海峰棋院網站（www.haifong.org）取得資料**，
包括職業棋士名錄、棋士簡介、新聞、比賽訊息、抽籤結果等，並顯示在協會官網上。
協會沒有另外建立一份棋士資料，**院方網站就是唯一的來源**。

因此網站改版後，協會官網會受到直接影響。這份文件列出：

1. 改版時**最需要注意的一件事**（棋士編號）
2. 請保留的**舊網址轉址**
3. 協會目前讀取的網址清單（供貴公司評估）
4. 建議改用的**資料介接方式**（對雙方都比較穩）
5. 希望配合的時程

協會這邊所有程式都可以配合修改，**只要事先知道會變成什麼樣子**。
最怕的是上線後才發現，因為那時協會官網上的棋士資料已經停止更新了。

---

## 1. 最重要：棋士編號請不要更換

目前海峰棋士個人頁的網址是這樣：

```
https://www.haifong.org/profession/venue/524D63AB167F4AC82887FD1660977B3E
                                          └──────────── 棋士編號 ────────────┘
```

**這串編號是協會系統用來辨識棋士身分的唯一鍵值**，目前被用在：

| 用途 | 說明 |
|---|---|
| 棋士登入帳號 | 棋士登入協會官網後，靠這個編號找到自己的資料 |
| 對局費紀錄 | 每位棋士的對局費、獎金排名 |
| 個人 AI 分析 | 貴院「棋士研究室」的 89 位棋士連結，也是用這個編號對應 |
| 年度成績介接 | 協會提供給貴院的 `player-stats.json`，就是以這個編號為鍵 |
| 賽事報名、名冊 | 報名紀錄與名單產生 |

**如果新網站重新產生棋士編號，以上全部會對不起來**——棋士登入後會變成查無資料，
對局費、個人分析、成績都會消失，協會必須逐筆人工比對 139 位棋士才能修復。

### 請求

- **最佳做法**：沿用現有編號。
- **若技術上必須更換**：請提供一份新舊對照表（CSV 或 JSON 皆可），格式如下即可：

```csv
old_id,new_id,name
524D63AB167F4AC82887FD1660977B3E,P0001,周俊勛
```

有這份對照表，協會可以整批轉換，不需要人工處理。

---

## 2. 請保留舊網址的轉址（301）

協會官網上有大量連回貴院網站的連結，以及已轉存的新聞內容。
舊網址若直接消失，協會官網會出現大量失效連結與破圖。

| 舊網址 | 用途 | 影響數量 |
|---|---|---|
| `/profession`　`/profession/venue/<編號>` | 棋士名錄與個人頁 | 139 位 |
| `/news`　`/news/content/<編號>` | 新聞原文連結 | 132 篇已轉存 |
| **`/upload/news/*.jpg`、`*.png`** | **新聞內文圖片** | **369 張** |
| `/elite` | 精銳隊頁面 | 1 個連結 |
| `/game/classes/<編號>` | 競賽規則頁面 | 1 個連結 |

### 特別提醒：圖片網址

協會官網的新聞是**把內文轉存在協會這邊**，但**圖片仍然直接引用貴院網址**
（這是當初為了不重複佔用貴院的流量與版權考量所做的決定）。

因此 `/upload/` 底下的圖片網址一旦變更或刪除，
**協會官網上 132 篇新聞、369 張照片會同時變成破圖**，而且無法自動修復。

→ 請務必保留 `/upload/` 的原有路徑，或提供新舊圖片網址的對照規則。

---

## 3. 協會目前讀取的網址清單

供貴公司評估改版影響範圍。這些都是**公開頁面的唯讀存取**，不涉及任何帳號。

| 網址 | 取得的內容 |
|---|---|
| `/profession` | 職業棋士名單（139 位） |
| `/profession/venue/<編號>` | 段位、簡介、頭銜、歷史成績、照片 |
| `/news`、`/news/<數字>` | 新聞列表（分頁） |
| `/news/content/<編號>` | 新聞內文 |
| `/game`、`/game/<編號>`、`/game/classes/<編號>` | 比賽訊息與競賽規則 |
| `/elite` | 精銳隊名單 |

### 存取方式

- **頻率**：每天台灣時間 **20:17** 一次，單日總請求量約 20～40 次（文章轉存每批最多 10 篇、間隔 3 秒）
- **識別**：所有請求都帶有下列 User-Agent，便於貴公司在記錄中辨識或設定白名單

```
CPGA-site-builder/1.1 (+https://cpga.org.tw; CPGA official site data sync)
```

- 若回應 403 / 429 / 503，協會的程式會自動整批停止、隔天再試，不會重複施壓
- 協會的程式都設有保護機制：**解析結果異常時會中止並保留原有資料**，
  不會用空資料覆蓋。因此改版當天協會官網不會變成空白，但資料會停止更新。

---

## 4. 建議：改用資料介接（JSON），不要讓協會繼續解析網頁

目前協會是**直接解析 HTML 畫面**取得資料。這種做法的缺點是：
貴公司只要調整版面，協會這邊就會壞掉，而且雙方都不會立刻知道。

既然這次要重做網站，**這是改成正式介接的好時機**。
協會希望能改讀三份 JSON，貴公司只要在新站輸出這三個檔案（靜態檔即可，不需要 API）：

### 4-1. 棋士名錄

```json
{
  "generated": "2026-11-24T20:00:00+08:00",
  "players": [
    {
      "id": "524D63AB167F4AC82887FD1660977B3E",
      "name": "周俊勛",
      "rank": "九段",
      "photo": "https://www.haifong.org/……（棋士照片網址）",
      "url": "https://www.haifong.org/profession/venue/524D63AB...",
      "titles": "冠軍數: 50冠 (含國際賽1冠)",
      "bio_html": "<p>1980年2月23日生……</p>"
    }
  ]
}
```

### 4-2. 新聞列表

```json
{
  "items": [
    {
      "id": "F53E8FC02DEB96E9EB07DB44EB25D31F",
      "title": "……",
      "date": "2026-11-20",
      "category": "比賽訊息",
      "url": "https://www.haifong.org/news/content/F53E...",
      "summary": "……",
      "content_html": "<p>……</p>",
      "images": ["https://www.haifong.org/upload/news/xxx.jpg"]
    }
  ]
}
```

### 4-3. 抽籤結果（對戰組合）

這一份對協會最重要，見下一節。

> 協會已經有兩份同類型的規格文件可供參考格式：
> 《棋士年度成績介接說明》《賽程資料交換規格》。
> 欄位名稱可由貴公司決定，協會配合即可，**重點是有固定格式、不會隨版面改動**。

---

## 5. 抽籤結果公告：目前最脆弱的一環

協會官網的「我的賽程」與棋士個人頁的「今後賽程」，
是**解析抽籤結果公告的正文純文字**取得的，格式大致如下：

```
9/22(二)10:00資格賽對陣：
徐銘均初段 vs 林聖弈三段
9/29(二)10:00初賽(左半區)1回對陣：(上、下午各一局)
林彥丞五段 vs (黃柏人初段 vs 柯沛辰初段)勝者
```

協會的程式必須從這段文字裡判讀日期、時間、輪次、雙方姓名與段位，
再用棋士名錄比對切出姓名。**公告的寫法只要改變，就會解析失敗。**

棋士會依這份資料安排當天行程，顯示錯誤的對手或時間，比顯示不出來更嚴重。

### 請求（擇一即可）

- **最好**：新網站輸出結構化的對戰資料（日期、時間、棋戰、輪次、雙方棋士編號）
- **或**：維持目前公告正文的寫法不變，改版前告知協會

---

## 6. 請在上線前提供測試站

協會需要在新站正式上線**之前**，先用測試網址跑一次全部的抓取程式，
確認格式無誤、編號對得上，並把程式改好。

- 需要的時間：測試站可用後約 **3～5 個工作天**
- 測試站如需帳號密碼或 IP 限制都沒問題，協會可配合

**請在切換前至少兩週告知預定上線日期。**

---

## 7. 這次改版不會動到的系統（確認用）

以下是貴院的其他系統，協會官網同樣有使用。
院方已表示這次**不在改版範圍內**，列出供貴公司確認，避免一併遷移：

| 系統 | 協會官網的用途 |
|---|---|
| 成績系統（對局紀錄資料庫） | 棋士年度成績、近期對局、升段進度 |
| 棋譜系統（HiGO） | 每一局的「看棋譜」連結 |
| 棋士研究室（個人 AI 分析） | 職業棋士專區的個人分析連結 |
| 對局費資料（專用網址） | 棋士對局費與獎金排名 |
| 公開行事曆（Google 日曆） | 全站賽程與賽事月曆 |

**若其中任何一項會跟著調整，請務必事先告知協會**，
否則對應功能會在切換當天停止。
